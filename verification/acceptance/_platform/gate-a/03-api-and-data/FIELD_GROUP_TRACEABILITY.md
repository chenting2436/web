## 实现时的逐字段完成规则

每个字段必须记录 legacy source/line、React component/control、OpenAPI schema/property、PostgreSQL column 或 object manifest path、nullable/default/enum/unit、读写权限、审计分类、迁移转换、合法/边界/恶意 fixture 和测试 ID。缺任一列时该模块字段迁移不得标记完成。
